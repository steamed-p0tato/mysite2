// 01 · MODEL LINEUP

One Latent Core. Three Execution Targets.

Every jLFM variant shares the same bidirectional semantic chunk encoder and continuous-time liquid state integrator—swapping only the readout head for generation, typed decisions, or silicon execution.

CORE_01 // GENERATIVE Pre-Release

JLD

JEPA Liquid Decoder · Generative LM

A hierarchical generative model that plans ahead in chunk-level latent space before decoding tokens locally. By predicting semantic trajectories first, JLD avoids flat token-by-token drift under a strict 200M parameter cap.

  • ├─ Latent Horizon Planning: Predicts future semantic chunks via a stacked CfC liquid core before emitting prose.
  • ├─ 32× Context Compression: Compresses token windows into dense latent vectors with anti-collapse regularization.
  • └─ Local-First Footprint: Runs effortlessly on edge GPUs, Apple Silicon, and homelab nodes.
<200M Param Cap
JEPA+AR Hybrid Core
Stream Output
CORE_02 // DISCRIMINATIVE System-1 Engine

JLC

JEPA Liquid Choice · Typed Decision Model

Our sovereign, self-hostable answer to TypeSafe’s Jev. State goes in; calibrated typed decisions come out in a single forward pass. No prose generation, no chain-of-thought tax, and 0% off-schema hallucination.

  • ├─ 3 Native Primitives: Evaluate Noul (binary probability), Choice (categorical), and Score (ordinal rubrics) in parallel.
  • ├─ Calibrated by Design: Trained with proper scoring rules (Brier + Ordinal RPS) so a 0.85 confidence means 85% empirical accuracy.
  • └─ Zero Output Token Cost: Score 20+ routing, guardrail, or RAG reranking questions in one pass.
<50M Param Cap
1-Pass Parallel Eval
Typed JSON Out
CORE_03 // HARDWARE + SDK Silicon Target

JL-FPGA

Hardware JLC + OSS Neural Engine SDK

A general-purpose, quantized edition of JLC engineered for low-power FPGAs, bundled with an open-source Neural Engine SDK. Bring deterministic, microsecond-class System-1 decisions straight to the physical edge.

  • ├─ KV-Cache Free Recurrence: Liquid CfC state integration keeps memory bandwidth flat and deterministic on BRAM/SRAM.
  • ├─ OSS Neural Engine SDK: Open Verilog/SystemVerilog cores, compiler toolchain, and zero-dependency C/Rust host drivers.
  • └─ Physical Edge Ready: Built for robotics, industrial safety interlocks, SDR/network packet gating, and autonomous hardware.
